
Project name : Fitlog.

Short description: A website that helps people become fit.

Technologies used: JavaScript, TypeScript, Tailwind, Next.js

5 key features of the project: 
        1. Responsive for mobile, tablet and desktop.
        2. Fully interactive. 
        3. Has features like sorting, counting calories, minutes.
        4. Can add different exercises on todays' plan. 
        5. Can even save those exercises for later.
